# CivNodes Map

A static map for CivNodes. Website files live in `site/`; tiles and map bounds live in
[`civnodes-map-tiles`](https://github.com/ColtSaboteur/civnodes-map-tiles), cloned at `site/map-data/`.
Photosphere images and locations live in
[`civnodes-map-panoramas`](https://github.com/ColtSaboteur/civnodes-map-panoramas), cloned at `site/panoramas/`.

See [updating map data and previewing locally](docs/updating.md).
